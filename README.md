# Exercícios

Repositório com exercícios e projetos práticos desenvolvidos ao longo da graduação em Ciência da Computação (UniFAJ), cobrindo programação orientada a objetos, banco de dados, e lógica de programação em diferentes linguagens.

## 📁 Estrutura

```
Exercicios/
├── C++/        # Exercícios de lógica e estruturas em C++
├── JAVA/       # Projetos de POO, Spring Boot e Android
├── PYTHON/     # Exercícios de estatística, matemática discreta e lógica
└── SQL/        # Exercícios de banco de dados (JOINs, normalização, GRANT/REVOKE etc.)
```

### C++
Exercícios introdutórios de lógica de programação e estruturas básicas da linguagem.

### JAVA
Projetos e exercícios de Programação Orientada a Objetos (POO), incluindo:
- Herança, classes abstratas e interfaces
- APIs REST com Spring Boot
- Aplicativos Android (ex: sistema de gerenciamento de mesas de restaurante, lanchonete)
- Exercícios do livro Deitel

### PYTHON
Exercícios de introdução à análise estatística de dados, matemática discreta e lógica de programação, incluindo notebooks Jupyter (`.ipynb`).

### SQL
Exercícios de banco de dados cobrindo:
- Consultas com JOIN e GROUP BY
- Normalização (1FN, 2FN, 3FN)
- Gerenciamento de usuários (GRANT/REVOKE)

## 🎓 Contexto

Todos os exercícios foram desenvolvidos como parte das disciplinas do curso de **Bacharelado em Ciência da Computação** na **UniFAJ – Centro Universitário de Jaguariúna**.
